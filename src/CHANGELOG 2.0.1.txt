UNSC Core Continued 2.0.1
=========================

NEW SHIPS
---------
- Added Lancer-class Heavy Escort Attack Corvette.
  - Core hull ID: unsc_cc_corvette_lancer
  - Authored Escort Autofit/fleet variant.
  - Uses built-in 5D7C2 Light MAC, current Core Rampart PD, and Streak PD.
- Added Anlace-class Advanced Escort Frigate.
  - Core hull ID: unsc_cc_frigate_anlace
  - Authored "Adv Escort" and "E-War" Autofit/fleet variants.
  - Uses built-in Helios High Energy Laser and intended Vanilla support weapons.

NEW WEAPONS
-----------
- Added 5D7C2 Light MAC (unsc_cc_5d7c2_light_mac).
- Added Streak PD System (unsc_cc_streak_pd_system) and namespaced Streak
  projectile.
- Added Helios High Energy Laser (unsc_cc_helios_high_energy_laser).
- Reused validated Core MAC/Rampart/Spartan support assets where the Stargazer
  source bytes/behavior matched existing Core resources rather than duplicating
  inherited content.

AUTOFIT / PRESENTATION
----------------------
- Lancer Escort, Anlace Adv Escort, and Anlace E-War variants are exposed as
  player Autofit goal variants.
- Shortened the two Anlace Autofit labels to avoid UI overlap.
- Replaced the imported Lancer sprite with the user-cleaned final sprite while
  preserving its 98x251 canvas and alignment bounds.
- Standardized all active Core weapon design/manufacturer rows to "UNSC Core"
  for consistent Codex/production presentation.

SOURCE-INTEGRATION CLEANUP
--------------------------
- Corrected the source Lancer hull-name carryover from "Mako" to "Lancer".
- Corrected the Anlace Electronic Warfare technical spelling from "warefare" to
  "warfare" in the Core namespace.
- Corrected "Helios Hign Energy Laser" to "Helios High Energy Laser".
- Lancer and Anlace use the existing unsc_cc_bp blueprint package path; no new
  package item is required.
- No Stargazer Java/JAR code is imported for this subset.

VERSION / UPDATE METADATA
-------------------------
- Release version: 2.0.1.
- Packaged Version Checker declaration now carries forum thread ID 36142, matching
  the post-2.0.0 GitHub main-branch metadata correction.
- Core and legacy update channels remain separate.

COMPATIBILITY
-------------
- 2.0.1 keeps the established Core 2.x technical namespace and is compatible
  with existing Core 2.0.0 saves; no 2.0.0 -> 2.0.1 migration is required.
- Existing campaigns that already consumed the UNSC Blueprint Package may need
  to obtain/use another copy of the package to learn the newly added blueprints;
  package consumption records specific known IDs rather than a persistent tag.
- The existing external 1.3.1 -> 2.0.0 migration path remains the legacy-to-Core
  migration route because 2.0.1 does not alter the Core namespace.
- No additional Stargazer expansion hulls beyond Lancer + Anlace are included.
